# Code of conduct

## Commitment

This project exists so that people can run their own radio receiver without fighting their operating system. Anyone taking part, whether contributing code or just reporting a problem, should be able to do so without harassment, regardless of age, disability, gender identity or expression, level of experience, nationality, appearance, ethnicity, religion or sexual orientation.

## Expected behaviour

- Use welcoming and respectful language.
- Take technical criticism in good faith, and criticise ideas rather than people.
- Assume the other person knows something you do not. In a project about hardware, they usually do.
- Remember that not everyone is a native English speaker, and that this project is bilingual on purpose.

## Unacceptable behaviour

- Harassment, insults, or personal or political attacks.
- Sexualised language or imagery.
- Publishing someone else's private information without permission. This includes receiver coordinates: they are a home address.
- Sustained disruption of discussions.

## Scope

This applies to the repository, its issues and pull requests, and any space where someone is representing the project.

## Enforcement

Report unacceptable behaviour to **not.announced@simplelogin.fr**. Reports are handled confidentially. Whoever maintains the project may remove comments, close discussions or block accounts when necessary.
